# 美术方向：孤独的风景

## 当前方向

从古诗文的视觉演绎转向可以独自停留的自然空间。第一处是雨夜、山林与篝火，暂名「雨歇之前」。前一版风、花、雪、月十二诗境计划已停止，不是待实现的产品路线。

这里的孤独来自空间与声音：近处有可以依靠的一点温度，远处是看不尽的雨林。保持观察者视角，不加入人物、任务、战斗、计分、背包或需要处理的生存指标。

仓库和作品仍叫「云烟集」。先把一个地方做完整，再考虑其他风、雨、旷野或水边的场景。

## 第一处：雨歇之前

视角在林边的布棚下。下垂的棚沿、缝边和拉绳只在画面边缘交代遮蔽与受力关系，不能围成占据画面中心的门框。几步之外有一堆柴火，地势略高；浅水沿旁边低洼处断续聚集，倒映晃动的火光。雨从棚外斜落，远处的林木逐层淡入灰冷的雨雾。

镜头接近坐着看火的高度，避免俯视模型。横屏给树林与水面留出空间，竖屏保持火堆和雨中的视线通道；不能只裁掉左右两边。

### 层次与尺度

| 层次 | 内容 | 需要看见的关系 |
| --- | --- | --- |
| 近处 | 布棚边、湿土、腐叶、细砾、断枝、苔丛、蕨叶和积水 | 棚沿遮雨，地面有高差；材质细节按厘米和毫米变化，杂物成簇而非均匀撒满 |
| 中近处 | 柴火、灰床、炭块、低石圈 | 木柴有重量，炭床比火焰更持久，暖光照到周围实物 |
| 中景 | 雨线、成熟树干、较年轻枝叶、土岸灌丛与疏落石块 | 雨有远近与风向，树木与林下植物有前后遮挡和不均匀疏密 |
| 远景 | 逐渐稀薄的林层、冷雾与阴云 | 远处仍有轮廓和空间，雾不能成为掩盖空场景的平面 |

当前实现已将树林从旧雪松生成器中独立出来，使用曲线树干和分枝、折面叶片、程序树皮表面与地表散落物。土壤和树皮的颜色、法线、粗糙度由共同结构生成，避免互不相关的颜色噪声与凹凸。完成这些生成方式并不等于画面已通过写实验收。

生成规则也需要表达地物之间的关系：根部和倒木附近积聚深色腐殖层，踩踏处较少完整落叶，低洼岸边保留泥叶过渡，灌丛集中遮住部分树根。当前地材与散落物已接入共同的腐殖层、踩踏、根部和苔丛分布；土岸上增加了错落的低矮灌丛与蕨类，冠下和水线附近有局部腐叶、碎枝堆积。实际聚集与遮挡效果仍需从画面判断。树皮不应成为整根平行拉丝或描黑蜂窝，苔藓不应形成边界完整的绿色地毯；这些是持续实拍校准的目标。

### 火与光

火焰应有不断分离又汇合的火舌、内部空隙、上升速度差和稀疏火星。形状由三维密度场计算，不能像旋转的橙色图标、实心圆锥或一整块发光果冻。白热核心只占很小部分，外缘保留橙黄层次；克制辉光，避免大面积过曝光球。

灰、炭、木柴及其相互遮挡先成立，再调整亮度。火光照亮身边湿石和木头，木柴、石圈与近处树根需要打断光照；当前中高画质使用缓存的近处点光源阴影。反射由真实火堆产生，不能另画一个永远不变的橙色倒影。冷暖对比来自照明，而不是覆盖整屏的蓝橙滤镜。

阴雨天光需要保留暗部材料差异和树干宽泛的明暗转折。让程序环境光补充层次，有方向的灰冷天光交代形体，火光保留小范围温度。避免把环境照明抬成均匀灰色，也避免让土壤出现连续的金色镜面带。夜景不能用黑暗掩盖错误形体；截图仍要能辨认树干、地面、石块和棚沿的质地。

### 雨与水

雨线尺寸按距离变化，避免整屏同样长、同样亮的白线。接近火的雨滴可以略带暖色，远处主要由冷天光照亮。雨水不穿过棚顶；火与视点处在相同遮蔽逻辑下。

浅水沿地势分布，边缘有破碎和湿润过渡，不能成为一张完整的镜面地板。当前积水改为约 2–3 cm 的浅床，低泥脊与岸边残叶切断部分轮廓；从火旁泥地到水面应平缓连续，不能读成深坑或火堆台阶。水面反射随视角变化，较浅处仍透出实际泥底。小涟漪短促、位置不同，雨量控制同时影响雨线、落点和声场。反射要随相机、时间和画质正确更新，暂停时不自行运动。

### 声音

远雨铺开空间，近处有落在湿地和棚沿的不同颗粒感，柴火偶尔发出短促、干燥的爆裂。风的变化应缓慢而不整齐；火声更近、更集中，雨声更宽。

所有声音由合成生成。不用一段白噪声同时充当风、雨和火，也不加循环音乐强调情绪。音量为零需要真正安静。默认静音，用户主动开启后才建立声音；暂停、页面隐藏和上下文中断时一并处理。

## 视觉与声音验收

按真实浏览器截图和可听的声场判断，不根据 shader 行数、面数或自动测试通过判断美感。

当前版本仍处在视觉迭代中，尚未获得用户对写实效果的验收；以下各项是判断标准，不是已完成声明。

- 首眼是否读成一处可以停留的雨林空间，火是否是自然的视觉重心。
- 横竖屏和轻微转头后，棚、火、水、树林的空间关系是否仍成立。
- 木柴、石块与地面是否接触，是否出现悬空、穿插、重复图案或硬边框。
- 火焰是否在多个时刻保持真实感，而非仅一帧成立。
- 雨量变化是否有清楚但克制的反馈，水面与声场是否一致。
- 暗部是否仍有材料层次，火的亮度是否保留形状。
- 声音是否有远近，不出现明显循环接缝、持续电流声或过密爆裂。
- 手机上的构图、启动、发热和流畅度需要在真实设备复核；软件渲染截图不能代替。

界面只留必要的观看与声音控制。常态不介绍实现技术、不铺陈诗文、不摆放占据画面的功能卡片。
