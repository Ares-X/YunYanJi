# 云烟集 · YunYanJi

**在诗里的风景中，停留片刻。**

An interactive collection of landscapes inspired by classical Chinese poetry.

云烟集用实时生成的山水、风雪与声音，呈现古诗文中的意境。第一境取自《世说新语·言语》中的咏雪故事：**未若柳絮因风起**。

当前第一境是以人眼高度观看的**雪谷林溪**：连续雪岸、覆雪针叶林、裸树、岩石、半埋倒木与流动溪面组成同一处三维空间。项目正在持续校准形体、材质、光照与自然动势；细腻程度、真实感、诗意和真实设备表现仍需分别验收，自动化检查不代替视觉与听感判断。

## 开始

使用 Node.js 24 和 npm：

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。生产构建与本地预览：

```bash
npm run build
npm run preview
```

构建结果在 `dist/`，可部署到普通静态托管。资源使用相对路径，支持仓库子路径。项目没有后端、账号、模型 API、运行时 CDN 字体或素材请求。

## 体验

- 打开即可看雪；声音默认关闭。
- 拖动画面调整观看方向；轻划或按「起风」，风会同时改变雪片运动、溪面细波与环境声音。
- 在画面获得焦点时，空格起风，`P` 暂停／继续。
- 「诗文」查看原文与意境说明。
- 「入境」收起文字与工具，专注观看风景；点击「显字」恢复界面。
- 「设置」调整画质、音量和雪量，重看或分享同一处景色。
- 链接中的 `?seed=雪谷-01` 决定生成结果。相同种子复现相同初始构图与声音源，用户操作会改变后续体验。
- 尊重系统的减少动态效果偏好：初始画面静止，用户可以主动继续或起风。

## 作品规划

作品集计划分为**风、花、雪、月**四个主题，每个主题先做三个有鲜明代表性的诗境。当前集中打磨第一境「咏雪」；其余诗境仍在候选阶段，没有加入未完成的切换入口。十二景候选、原文来源与视觉验收目标见 [美术方向与诗境规划](docs/art-direction.md)。

## 全程序化原则

**不使用预制图片贴图、HDRI、天空盒图片、模型文件、录音、视频或其 base64 嵌入形式。**

| 部分 | 实现 |
| --- | --- |
| 雪岸、岩石、树干、枝系与倒木 | 连续高度场、参数化曲面、曲线和有种子的形态生成；按材质合并静态几何 |
| 针叶 | 算法在运行时栅格化枝梢与细针，生成并缓存 DataTexture；弯曲交叉枝片承载带透明轮廓的针叶分布 |
| 雪、木、树皮与石 | 标准 PBR 材质结合米制坐标的解析 GLSL 噪声，计算颜色、粗糙度与微表面法线；断木端面另有程序年轮 |
| 天空与环境光 | Three.js 解析大气散射与程序云；运行时生成并缓存 PMREM 环境光，太阳方向与方向光一致 |
| 阴影与局部遮蔽 | 静态树影缓存、较弱的近地遮蔽场，以及中高档复用主画面深度的半分辨率 GTAO |
| 溪面、薄冰与岸霜 | Reflector 捕获当前场景的平面倒影，结合流动噪声导数、冰霜边缘与反射缓存 |
| 风雪 | 有种子的粒子分布、解析雪片轮廓、按秒推进的风场 |
| 风声与木质共振 | 有种子的 PCM 合成、滤波、声像和增益控制 |
| 界面 | DOM、CSS、系统字体 |

算法生成的 GPU 纹理、实时阴影图和内存 PCM 是允许的运行时数据。材质源仍是代码与参数，不是外部素材。禁止把固定素材隐藏在字符串或数组中绕过约束。`npm run check:assets` 是静态防回归检查，仍需配合代码审查与浏览器网络验收。

## 结构

```text
src/
  core/             种子、时间、共享风雪状态与分享链接
  scenes/
    types.ts        诗境接口
    registry.ts     诗文内容与场景注册
    snow/           雪谷、林木、溪流、地表细节与风雪
  render/           Renderer、大气、相机、画质、材质与后处理
  audio/            PCM 合成、音频图与浏览器生命周期
  ui/               低干扰界面、原文与设置
  main.ts           输入、生命周期及子系统装配
tests/
  unit/             生成、时钟、音频生命周期与画质预算
  browser/          实际渲染、声音、交互、响应式与上下文恢复
```

模拟状态不依赖 Three.js 对象。声音和画面读取同一份 `EnvironmentSnapshot`。几何、天气和声音使用独立的随机流，修改音频不会改变景物。

`createSnowWorld.ts` 装配首景，`snowLandscape.ts` 统一地形与溪岸，`forestTrees.ts`／`forestNeedles.ts` 生成林木与针叶，`forestFloor.ts` 生成倒木及零散枯草，`snowStream.ts` 管理溪面和反射。`winterTree.ts` 仍用于林中少量裸树。当前没有建筑或局部暖灯。

新增诗境时，实现 `PoemScene`（`group`、相机位置、`update`、`setQuality`、`dispose`），并在 `registry.ts` 注册。不要复制整个应用循环。接口设计与运行约束见 [架构说明](docs/architecture.md)。

## 画质与生命周期

| 档位 | 雪片上限 | 树影 | 溪面反射 | GTAO／MSAA | 内部像素上限 |
| --- | ---: | --- | --- | --- | ---: |
| 轻盈 | 1,600 | 关闭 | 256² | 关闭／关闭 | 850,000 |
| 均衡 | 3,800 | 1,024² | 384² | 半宽半高，6 样本／2× | 1,500,000 |
| 细腻 | 6,800 | 2,048² | 512² | 半宽半高，12 样本／4× | 3,000,000 |

地形与树木目前是静态几何，方向光阴影在初次绘制、画质设置或上下文恢复后更新，再复用阴影图。各档位另共用启动时生成的 1,024² 近地遮蔽缓存；它只是近地辅助，不能覆盖所有起伏地形。GTAO 复用主画面的 DepthTexture，不为法线额外重画整个森林。所有档位使用相同的线性 HDR 与输出转换；没有景深或 bloom。

自动档按屏宽与输入方式选择起始档位，尚未依据实测 GPU 帧耗时动态调节。画质切换复用景物与粒子几何。树木的近、中、远细节层次在场景生成时按布置选择，不是随相机逐帧切换的 LOD。

溪面细波与反射使用共享模拟时间。静止视角下，倒影最多按每 1/8 秒一次的节奏刷新，其余帧复用；视角、投影、溪面变换、雪量或反射尺寸改变，以及重看此境，会在需要时提前刷新。它是当前场景的实时平面反射，不是预制景物贴图。

暂停、阅读诗文、切到后台或 WebGL 上下文丢失时，模拟与音频同步停止。设置弹窗会暂停画面，并保留已经开启的声音，方便听着调节音量；恢复后不补算离开期间的时间。WebGL 恢复时重新生成环境光与近地遮蔽，重建后处理目标，并使树影和溪面反射在后续绘制刷新。页面退出会释放生成纹理、渲染目标、几何、材质、音频、事件和观察器。

## 验证

```bash
npm run check
npx playwright install --with-deps chromium
npm run test:browser
```

日常看图直接运行：

```bash
npm run capture
```

命令会构建页面、启动临时本地服务、截取桌面和手机画面，然后关闭服务与浏览器。结果写入 `test-results/captures/`，包括两张 PNG 和记录实际渲染器、画面指标及浏览器错误的 `capture.json`。无需推送 GitHub 或调用截图服务。已经安装 Chrome 的电脑也可以使用：

```bash
PLAYWRIGHT_CHROMIUM_CHANNEL=chrome PLAYWRIGHT_SOFTWARE_RENDERING=0 npm run capture
```

CI 保留最终质量检查：草稿 PR 运行素材约束、类型、单元测试与构建；正式 PR、主分支和手动运行增加浏览器验收。只在失败或手动要求时上传浏览器报告，保留 3 天。连续推送取消旧任务；文档路径过滤的适用边界见 [浏览器验收说明](docs/browser-validation.md)。

默认测试和截图采用软件渲染，耗时不能代表真实手机或桌面 GPU 性能。关闭强制软件渲染只是让浏览器自行选择 GPU，实际使用哪种渲染器应查看 `capture.json`。截图可以验证构图和 Shader 是否正确执行，真实设备流畅度与主观听感还需要分别验收。

开发诊断：在 URL 添加 `?debug=1`，控制台调用 `window.__YUNYANJI__.getState()`。`calls`／`triangles` 包含当前帧的阴影、反射与后处理绘制；`reflectionUpdates`／`reflectionSize` 记录反射缓存状态，`ambientOcclusion`／`occlusionWidth`／`occlusionHeight` 记录 AO 配置。缓存刷新帧与复用帧的工作量不同，这些计数不等于 FPS。默认界面不显示技术指标。
