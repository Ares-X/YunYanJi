# 云烟集 · YunYanJi

**在诗里的风景中，停留片刻。**

An interactive collection of landscapes inspired by classical Chinese poetry.

云烟集用实时生成的山水、风雪与声音，呈现古诗文中的意境。第一境取自《世说新语·言语》中的咏雪故事：**未若柳絮因风起**。

当前交付是可运行、可扩展的程序化框架与第一处雪庭。后续美术工作将继续提升材质尺度、积雪形态、光照层次、声音质感和真实设备表现。

## 开始

使用 Node.js 24 和 npm：

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。生产构建与本地预览：

```bash
npm run build
npm run preview
```

构建结果在 `dist/`，可部署到普通静态托管。资源使用相对路径，支持仓库子路径。项目没有后端、账号、模型 API、运行时 CDN 字体或素材请求。

## 体验

- 打开即可看雪；声音默认关闭。
- 轻划画面或按「起风」，风会同时改变雪片运动和环境声音。
- 在画面获得焦点时，空格起风，`P` 暂停／继续。
- 「诗文」查看原文与意境说明。
- 「设置」调整画质、音量和雪量，重看或分享同一处景色。
- 链接中的 `?seed=雪庭-01` 决定生成结果。相同种子复现相同初始构图与声音源，用户操作会改变后续体验。
- 尊重系统的减少动态效果偏好：初始画面静止，用户可以主动继续或起风。

## 全程序化原则

**不使用预制图片贴图、HDRI、天空盒图片、模型文件、录音、视频或其 base64 嵌入形式。**

| 部分 | 实现 |
| --- | --- |
| 庭院、屋檐、月门、石阶与树木 | 参数化几何、曲线和有种子的形态生成 |
| 雪、木、石、抹墙、屋瓦 | 标准 PBR 材质结合世界坐标 GLSL 噪声；计算颜色、粗糙度与微表面法线 |
| 天空与环境光 | 解析天空着色器，运行时生成并缓存 PMREM 环境光 |
| 风雪 | 有种子的粒子分布、解析雪片轮廓、按秒推进的风场 |
| 风声与木构声 | 有种子的 PCM 合成、滤波、声像和增益控制 |
| 界面 | DOM、CSS、系统字体 |

算法生成的 GPU 纹理、实时阴影图和内存 PCM 是允许的运行时数据。材质源仍是代码与参数，不是外部素材。禁止把固定素材隐藏在字符串或数组中绕过约束。`npm run check:assets` 是静态防回归检查，仍需配合代码审查与浏览器网络验收。

## 结构

```text
src/
  core/             种子、时间、共享风雪状态与分享链接
  scenes/
    types.ts        诗境接口
    registry.ts     诗文内容与场景注册
    snow/           首个雪庭的几何与风雪
  render/           Renderer、天空、相机、画质与材质
  audio/            PCM 合成、音频图与浏览器生命周期
  ui/               低干扰界面、原文与设置
  main.ts           输入、生命周期及子系统装配
tests/
  unit/             生成、时钟、音频生命周期与画质预算
  browser/          实际渲染、声音、交互、响应式与上下文恢复
```

模拟状态不依赖 Three.js 对象。声音和画面读取同一份 `EnvironmentSnapshot`。几何、天气和声音使用独立的随机流，修改音频不会改变庭院。

新增诗境时，实现 `PoemScene`（`group`、相机位置、`update`、`setQuality`、`dispose`），并在 `registry.ts` 注册。不要复制整个应用循环。接口设计与运行约束见 [架构说明](docs/architecture.md)。

## 画质与生命周期

| 档位 | 雪片上限 | 阴影 | 内部像素上限 |
| --- | ---: | --- | ---: |
| 轻盈 | 1,600 | 关闭 | 850,000 |
| 均衡 | 3,800 | 1,024² | 1,500,000 |
| 细腻 | 6,800 | 2,048² | 3,000,000 |

自动档按屏宽与输入方式选择起始档位；这是静态选择策略，尚未依据实测 GPU 帧耗时动态调节。画质切换复用粒子几何。

暂停、阅读诗文、切到后台或 WebGL 上下文丢失时，模拟与音频同步停止。设置弹窗会暂停画面，并保留已经开启的声音，方便听着调节音量；恢复后不补算离开期间的时间。WebGL 恢复时重新生成环境光。页面退出会释放 GPU、音频、事件和观察器。

## 验证

```bash
npm run check
npx playwright install --with-deps chromium
npm run test:browser
```

CI 在每个 PR 上执行相同流程，并上传桌面／手机截图、运行指标和失败 trace。浏览器测试采用软件渲染以保证 CI 可重复运行；其耗时不能代表真实手机或桌面 GPU 性能。截图可以验证构图和 Shader 是否正确执行，真实设备流畅度与主观听感还需要分别验收。

开发诊断：在 URL 添加 `?debug=1`，控制台调用 `window.__YUNYANJI__.getState()`。默认界面不显示技术指标。
